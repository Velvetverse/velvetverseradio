Android — Instalar / Install

  1. Abra o player através do botão acima.Open the player using the button above.

  2. Add

    Toque em «Instalar VelvetVerse Radio» e confirme «Install».Tap “Install VelvetVerse Radio”, then confirm “Install”.

Se a janela não aparecer: Chrome ⋮ → Instalar aplicação / If no prompt appears: Chrome ⋮ → Install app.

iPhone — Instalar / Install

  1. Abra o player no Safari e toque no símbolo Partilhar.Open the player in Safari and tap Share (square with arrow).

  2. Escolha «Add to Home Screen» (se necessário, «View More»).Choose “Add to Home Screen” (tap “View More” if needed).

  3. ✓

    Deixe «Open as Web App» ligado.Keep “Open as Web App” enabled.

  4. Add

    Toque em «Add».Tap “Add”.
